# BOOK6MATCH7

Сайт для школьного проекта «Книга в эпоху цифровых технологий».

## Запуск на Windows
1. Установите Python 3.11 или новее.
2. Распакуйте архив и откройте папку `BOOK6MATCH7`.
3. В адресной строке Проводника напишите `cmd` и нажмите Enter.
4. Выполните:
   ```bat
   python -m pip install -r requirements.txt
   python app.py
   ```
5. Откройте http://127.0.0.1:5000

## Публикация на Render
Загрузите содержимое этой папки в GitHub, затем создайте на Render новый Web Service из репозитория. Настройки сборки и запуска находятся в `render.yaml`.

## Маршруты
- `/` — главная страница
- `/api/books` — каталог в JSON
- `/api/search` — поиск через POST
- `/health` — проверка работоспособности

В каталоге более 400 книг на русском языке. Число страниц указано приблизительно и зависит от издания.

## Жанры
- Драма
- Комедия
- Приключения
- Ужасы (хоррор)

Фильтры сочетают жанр, максимальное число страниц и предпочтение. Если подборка пустая, попробуйте увеличить объём или снять один из фильтров.

## Проверка
Запустите тесты командой `python -m unittest -v`.
